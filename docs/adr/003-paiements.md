# ADR 003 · Offres sans paiement

Statut : accepté pour phase 0.

Les tarifs des références visuelles (Free 0 €, Plus 2,50 €/mois, Pro 5 €/mois) sont affichés comme prévisionnels. Aucun achat, abonnement réel, Stripe, webhook ni facture n’est implémenté. Les actions de souscription sont désactivées.

La fiscalité, les prix définitifs et les droits associés restent à décider avant l’intégration de paiement d’une phase ultérieure.
