# Mobile · phase ultérieure

Aucune application Expo n’est créée en phase 0. Les gabarits Web sont responsive à partir de 320 px. À la phase mobile : TypeScript strict, contrats de packages/types, validation partagée, tokens sémantiques cohérents et composants natifs accessibles. Les contrats ne doivent pas importer le client Prisma. Les règles de navigation native et d’authentification seront documentées avant développement.
